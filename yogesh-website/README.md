# Yogesh Gupta - Website

React website for yogeshwebdeveloper.com

## Install & Run

```bash
cd yogesh-website
npm install
npm run dev
```

Open: **http://localhost:5173**

## Pages

- Home `/`
- About `/about`
- Services `/services`
- Work `/work`
- Testimonials `/testimonials`
- Blog `/blog`
- Contact `/contact`
