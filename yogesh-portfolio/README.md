# Yogesh Gupta - Portfolio Website

Fully responsive React homepage for [yogeshwebdeveloper.com](https://yogeshwebdeveloper.com).

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Responsive design (mobile, tablet, desktop)

## Getting Started

```bash
cd yogesh-portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```

## Sections

- Header with mobile menu
- Hero (14+ years experience)
- Services (8 cards)
- Stats bar
- City tags (SEO)
- Global hire section
- Engagement models
- Footer with contact & SEO links
